# Neovim Config

## Requirements

### Base

- Debian

```bash
sudo apt install fd-find fzf git luarocks neovim nodejs wget
```

- Fedora

```bash
sudo dnf install fd fzf git luarocks nodejs nvim wget
```

- macOS (Homebrew)

```bash
brew install fd fzf git luarocks neovim node wget
```

- Windows (Scoop)

```bash
scoop install fd fzf git luarocks neovim nodejs ripgrep wget
```

### Lazygit

- Follow the instructions for your OS at [Lazygit](https://github.com/jesseduffield/lazygit?tab=readme-ov-file#installation).


## Installation

Run the following command to clone this repository:

```bash
git clone https://github.com/Eddiore/neovim-config.git ~/.config/nvim/
```
