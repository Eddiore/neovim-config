# Neovim Config

## Requirements

### Base

- Debian

```bash
sudo apt install fd-find fzf git kitty luarocks neovim nodejs wget
```

- Fedora

```bash
sudo dnf install fd fzf git kitty luarocks nodejs nvim wget
```

- macOS (Homebrew)

```bash
brew install fd fzf git luarocks neovim node wget
```

- Windows (Winget)

```bash
winget install Neovim.Neovim sharkdp.fd junegunn.fzf DEVCOM.Lua OpenJS.NodeJS GNU.Wget2
```

### Lazygit

- Follow the instructions for your OS at [Lazygit](https://github.com/jesseduffield/lazygit?tab=readme-ov-file#installation).


## Installation

Run the following command to clone this repository:

```bash
git clone https://github.com/Eddiore/neovim-config.git ~/.config/nvim/
```
